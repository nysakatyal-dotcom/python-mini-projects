Python Mini Projects 
A collection of beginner-friendly Python programs created while learning programming as a second-year BCA student.
Projects
1. Student Grade Calculator
Accepts a student’s name and marks, assigns a grade based on marks, and validates that marks are between 0 and 100.
Concepts: Variables, user input, conditional statements.
2. Number Guessing Game
Generates a random number between 1 and 20, gives hints when a guess is too high or too low, tracks attempts, and handles invalid input.
Concepts: Loops, conditional statements, random module, exception handling.
3. Animated GIF Creator
Creates an animated GIF from two JPEG images using Python’s imageio library.
Files: create_gif.py, image1.jpg, image2.jpg
Concepts: Image processing, Python libraries, file handling.
Installation:
python3 -m pip install -r requirements.txt
Run the program:
python3 create_gif.py
The program generates an animated GIF named team.gif.
